|:---|:---|

| 📡 **Live Logging** | نمایش لحظه‌به‌لحظه با WebSocket |
| 💾 **خروجی JSON** | ذخیره و دانلود نتایج |
| 🔄 **چندین حالت اسکن** | سریع، معمولی، عمیق، کامل |
